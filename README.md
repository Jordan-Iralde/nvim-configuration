# Neovim Configuration

Configuración personal de Neovim orientada a desarrollo rápido, navegación de proyectos y construcción de un entorno de trabajo integrado.

## Estado — 2026-09-16

Durante esta sesión se trabajó principalmente sobre:

### Desarrollo

- LSP para C++ con `clangd`.
- LSP para TypeScript con `ts_ls`.
- LSP para Python con `pyright`.
- Integración de `ruff` para diagnóstico y linting de Python.
- Autocompletado con `blink.cmp`.
- Terminal integrada mediante `toggleterm.nvim`.
- Ajuste de `timeoutlen` para reducir la latencia al usar `<leader>`.
